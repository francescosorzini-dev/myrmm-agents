# Sicurezza

L'agent gira con i privilegi più alti del sistema (SYSTEM / root) ed esegue job che il server firma: la sicurezza sta nella firma e nei controlli, non nella segretezza del codice.

Per segnalare un problema usa **Security → Report a vulnerability** di questo repository (segnalazione privata). Non aprire una issue pubblica con i dettagli di una falla. Non pubblicare token, chiavi o indirizzi di server reali in issue, richieste o log.
